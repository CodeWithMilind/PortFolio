About me

I'm an entry-level Data Scientist in Pune with internship and project experience in data analysis, machine learning, and Python development. My work includes preparing data, building predictive models, and creating data pipelines and automation workflows.

I work with Python, SQL, Pandas, NumPy, and Scikit-learn for analysis and model development. My project work also includes data visualization, foundational NLP, and experimenting with LLMs through prompt engineering and the OpenAI API.

I'm continuing to build practical skills by developing data-focused applications and learning how to turn raw datasets into useful, clearly presented outputs.
